# advertiser-growth-prospecting

Work in progress — full README lands with the final commit.

Two-stage model for a quick-commerce ads platform:

1. **Conversion**: will a prospective brand become a paying advertiser within one quarter?
2. **Spend**: conditional on converting, how much will it spend in its first 90 days?

All data is synthetic and generated deterministically in-repo (`scripts/generate_data.py`) — nothing real, nothing external.
